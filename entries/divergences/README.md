# `divergences/`

Registered and empty. A divergence is two or more pathways over the same observations, told apart by one context dimension: the same transcript runs down a different pathway depending on which value the test case records, and one branch lands harder than the other. `coralmap.models.Divergence` validates an entry here. It is the counterpart of a contrast, which holds the situation fixed and varies the response. Nothing in the catalog is stated as a divergence yet.
